# Clinical AI Evaluation Lab

**CAIEL** — an evidence-grounded framework for evaluating the reliability, retrieval quality, grounding, and failure modes of LLM-based clinical question-answering systems.

> Portfolio engineering/research project. Not for patient care.

## Product
CAIEL is an evaluation laboratory rather than a simple medical chatbot. V1 uses a controlled depression-focused corpus and benchmark.

## Core capabilities
- Evidence-grounded clinical QA
- Source/citation inspection
- Retrieval evaluation
- Answer and grounding evaluation
- Experiment comparison
- Failure analysis
- Operational monitoring
