# Failure Taxonomy

## Retrieval
- Missing evidence
- Wrong document
- Wrong chunk
- Ranking failure

## Generation
- Hallucination
- Incorrect interpretation
- Incomplete answer
- Unsupported claim

## Citation
- Wrong citation
- Citation does not support claim

## Safety
- Overconfidence
- Missing uncertainty
- Potentially unsafe output

## System
- API failure
- Timeout
- Invalid output
