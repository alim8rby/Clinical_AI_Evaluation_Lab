# V5.3 — Retrieval Research Layer

## Goal

Turn retrieval from a single implementation into a controlled experimental variable.

V5.3 adds three comparable research strategies:

1. Dense retrieval — deterministic hashed-embedding baseline.
2. BM25 — deterministic lexical retrieval.
3. Hybrid — normalized dense + BM25 score fusion with configurable alpha.

The existing V4 production retrieval path is unchanged.

## Experiment contract

Every strategy is evaluated against the same:

- benchmark questions
- controlled corpus
- expected evidence mappings
- top-k
- retrieval metrics

For each question the research layer records:

- question ID
- strategy
- Precision@K
- Recall@K
- MRR
- nDCG
- measured retrieval latency

Results are aggregated into a strategy summary and a cross-strategy report.

## Reproducibility

The research layer uses deterministic ranking tie-breaks by chunk ID.

BM25 parameters default to:

- k1 = 1.5
- b = 0.75

Hybrid retrieval defaults to:

- alpha = 0.5
- alpha controls the normalized dense contribution
- 1-alpha controls the normalized BM25 contribution

The experiment must keep benchmark version, corpus, and top-k fixed when comparing strategies.

## Methodological boundary

The dense strategy in this research layer is intentionally the deterministic hashed-embedding baseline. The production PostgreSQL path can use semantic Ollama embeddings, but V5.3 does not silently mix embedding models into a retrieval comparison.

Semantic embedding comparisons can be introduced as an explicit experiment configuration later.

## Interpretation

V5.3 provides the machinery to answer questions such as:

> Does hybrid retrieval recover expected evidence more reliably than dense or lexical retrieval on the same benchmark?

It does not claim that one strategy is clinically superior. The benchmark remains a compact, engineered depression dataset.

## Limitations

- Controlled corpus remains small.
- Dense baseline is not a semantic embedding model.
- BM25 operates over the same compact corpus.
- Latency measurements are environment-dependent.
- No reranker is included in this milestone.
- Retrieval metrics depend on benchmark evidence annotations.

## Freeze boundary

V5.3 is complete when:

- dense, BM25, and hybrid strategies implement the same retrieval contract
- all strategies can be evaluated against ClinicalQA-v2
- comparable metrics are produced
- strategy comparison is deterministic apart from measured latency
- tests cover validation and comparison behavior
- production retrieval remains unchanged
- methodology and limitations are documented
