# V5.8 — Evidence Explorer 2.0

Status: **ENGINEERING COMPLETE**

## Purpose

V5.8 makes a completed run inspectable from the benchmark question through retrieval, answer claims, citations, chunks, and source documents.

The explorer is an inspection layer. It does not score clinical quality and does not replace the frozen evaluation metrics.

## Trace contract

The explorer exposes:

**Question → Evidence → Claim → Citation → Chunk → Document**

For each completed run it retains:

- benchmark question text and question ID;
- answer text and uncertainty;
- answer claims and their citation indices;
- citation records mapped to claim indices and chunk IDs;
- the exact retrieved chunks, rank, and retrieval score;
- whether each retrieved chunk was used by a citation;
- source document provenance.

## Retrieved-but-unused evidence

Retrieval traces are persisted per run. A chunk is marked used_in_citation=true when a persisted citation references its chunk ID.

A retrieved chunk with no citation reference is therefore explicitly surfaced as **retrieved only**. The explorer does not infer that a chunk was retrieved from document membership or citation order.

## Persistence

V5.8 adds the retrieval_traces table through migration 004_retrieval_trace.

The frozen Failure schema is unchanged.

## API

GET /api/v1/runs/{run_id}/evidence/explorer

The existing /runs/{run_id}/evidence endpoint remains unchanged.

## UI

The existing frontend gains a minimal Evidence Explorer panel. A run ID loads the question, answer, claims/citations, retrieved evidence, cited-vs-unused state, and document provenance.

## Determinism

Explorer output is ordered deterministically:

- claims by claim index;
- citations by claim index and citation ID;
- evidence by retrieval rank and chunk ID;
- documents by document ID.

## Limitations

- Retrieval traces only exist for runs executed after V5.8 persistence was introduced.
- Historical runs without retrieval traces cannot prove their original retrieved set.
- Citation linkage is based on persisted answer/citation records; it is not a human validation of citation correctness.
- The explorer provides provenance and inspection signals, not clinical safety validation.
- No empirical evidence-quality result is claimed by this phase.
