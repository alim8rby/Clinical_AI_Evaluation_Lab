# V5.1 — Human Annotation Rubric

## Purpose

This rubric defines how a reviewer should score the semantic evaluator's calibration sample. It is an evaluator-alignment exercise, not clinical validation.

Scores use a continuous 0–1 scale.

## Correctness

How accurately does the answer reflect the supplied reference answer and question?

- 0.0: substantively incorrect or contradicts the reference.
- 0.5: partly correct but contains a meaningful omission or error.
- 1.0: substantively correct with no meaningful error.

## Completeness

How fully does the answer cover the key concepts required by the benchmark item?

- 0.0: misses essentially all required concepts.
- 0.5: covers some required concepts but misses important ones.
- 1.0: covers all important required concepts.

## Relevance

How directly does the answer address the question without unnecessary material?

- 0.0: does not answer the question.
- 0.5: answers the question but includes substantial irrelevant material.
- 1.0: directly addresses the question with little or no irrelevant content.

## Faithfulness

How well are the answer's substantive claims supported by the supplied evidence?

- 0.0: claims are unsupported or contradicted by the supplied evidence.
- 0.5: some claims are supported, but meaningful unsupported content remains.
- 1.0: substantive claims are supported by the supplied evidence.

## Unsupported claim rate

What proportion of substantive claims are not adequately supported by the supplied evidence?

- 0.0: no meaningful unsupported claims.
- 0.5: a substantial minority of claims are unsupported.
- 1.0: essentially all substantive claims are unsupported.

This dimension is intentionally inverse to faithfulness.

## Review rules

1. Score only the material supplied for the calibration item.
2. Do not add outside clinical facts to make an answer appear better or worse.
3. Judge the answer against the benchmark reference and supplied evidence as specified for the dimension.
4. Record the score independently of the model score.
5. Do not change labels to improve agreement.
6. Preserve disagreements for later review rather than silently resolving them.

## Annotation record

Each label maps to:

- benchmark or run item identifier
- evaluation dimension
- human score
- corresponding frozen model score

The machine-readable schema is defined by `src/evaluation/calibration.py`.
