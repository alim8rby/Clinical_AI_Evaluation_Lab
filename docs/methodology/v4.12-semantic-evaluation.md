# V4.12 Semantic Answer & Grounding Evaluation

V4.12 adds model-assisted semantic evaluation without removing the deterministic metrics already used by V2.

## Answer quality

The evaluator scores:

- semantic correctness
- semantic completeness
- semantic relevance

The benchmark question, reference answer, key concepts, and generated answer are supplied to the evaluator.

## Grounding

The evaluator scores:

- semantic faithfulness
- semantic unsupported-claim rate

The evaluator receives the generated answer, its claims, and the retrieved evidence.

## Provider boundary

`SemanticEvaluationProvider` isolates model-assisted evaluation from the evaluation domain.

The current implementation uses local Ollama with structured JSON output and bounded scores in [0, 1].

## Baseline policy

Lexical V2 metrics remain stored alongside semantic metrics. This makes the improvement inspectable rather than silently replacing the original methodology.

Semantic evaluator versions are persisted with evaluation records.

## Important limitation

Model-assisted evaluation is not clinical ground truth. It can be biased by the judge model and may disagree with expert reviewers. The scores are evaluation signals, not clinical validation.

A future calibration set should compare semantic scores with human-reviewed benchmark labels.

## Freeze boundary

V4.12 changes evaluation instrumentation and metrics representation only. It does not change the failure taxonomy, clinical domain, benchmark questions, or V1–V3 retrieval/generation contracts.
