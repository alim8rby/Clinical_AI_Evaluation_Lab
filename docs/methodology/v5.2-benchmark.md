# V5.2 — ClinicalQA-v2 Benchmark Expansion

## Goal

Strengthen the benchmark without changing the frozen ClinicalQA-v1 baseline.

V5.2 introduces a separate benchmark-v2 contract and an initial 20-question expansion. The current v1 benchmark remains immutable for historical comparisons.

## New metadata

Each v2 question adds:

- question_type: fact, comparison, reasoning, scenario, or safety
- safety_relevance: explicit boolean flag

Existing benchmark fields remain:

- question_id
- question
- domain
- difficulty
- expected_evidence
- reference_answer
- key_concepts

## Current expansion

The v2 expansion contains 20 new questions using the existing controlled WHO and NICE evidence snapshots.

The expansion covers:

- direct factual questions
- comparisons
- multi-factor reasoning
- clinical scenarios
- safety-sensitive reasoning

Difficulty remains balanced across easy, medium, and hard questions.

## Evidence discipline

Every new expected evidence ID must resolve against the controlled corpus.

No new source text is introduced in this step. The benchmark therefore remains compact and reproducible, while the questions exercise more varied evaluation behavior.

## Version policy

ClinicalQA-v1 is frozen and must not be modified to support V5 experiments.

ClinicalQA-v2 is additive. A future v2 release can combine the frozen v1 questions with these new questions once their metadata is finalized and the combined payload is frozen.

Any change to a question's meaning, reference answer, safety label, or evidence mapping requires a new benchmark version.

## Limitations

The controlled corpus remains small and depression-only. The new questions improve evaluation coverage but do not make the benchmark clinically validated or statistically representative.

## Freeze boundary

V5.2 is still in progress. The current milestone establishes the versioned schema and first expansion set. Final V5.2 requires completing the combined benchmark, auditing coverage, and freezing the resulting payload.
