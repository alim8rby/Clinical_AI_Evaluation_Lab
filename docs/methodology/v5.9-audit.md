## Verification

Static repository inspection verified:

- the snapshot is canonicalized before hashing;
- evaluator and provider versions are captured at experiment creation;
- the experiment ID incorporates the snapshot;
- persisted configuration cannot silently change for an existing experiment;
- the API exposes the snapshot and hash;
- reports retain the reproducibility information;
- migration 005 is registered in database initialization;
- focused V5.9 tests are present.

Runtime tests were not executed in this environment. GitHub Actions remain informational because this repository has a known recurring CI environment failure.

## Freeze decision

V5.9 is frozen as an engineering reproducibility layer.

No claim of bit-for-bit LLM reproducibility or empirical reproducibility performance is made.
