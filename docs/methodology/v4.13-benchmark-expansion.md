# V4.13 Benchmark Expansion

## Scope

ClinicalQA-v1 remains depression-only and uses the existing controlled WHO/NICE evidence snapshots.

The benchmark grows from 8 to 40 questions.

## Design

The expansion adds:

- easy, medium, and hard questions
- direct factual questions
- multi-factor clinical reasoning questions
- multi-evidence questions
- treatment selection and follow-up scenarios
- non-response and relapse reasoning
- safety and early-treatment monitoring questions

Every expected evidence ID must resolve against the controlled corpus.

## Evidence discipline

No new clinical source text is introduced in this phase. Questions are grounded in the existing compact snapshots, so the benchmark remains reproducible and copyright-conscious.

The benchmark is still an engineering benchmark, not a validated or statistically representative clinical dataset.

## Version policy

Existing question IDs and meanings are preserved. New questions use IDs `cq-009` through `cq-040`.

Changes that alter an existing question, reference answer, or evidence mapping require a new benchmark version.

## Freeze

V4.13 is complete when the 40-question payload passes validation, evidence resolution, and CI.
