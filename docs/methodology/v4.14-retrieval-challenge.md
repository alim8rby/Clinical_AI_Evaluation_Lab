# V4.14 Retrieval & Evaluation Challenge Set

## Purpose

The core ClinicalQA-v1 benchmark measures ordinary benchmark performance. V4.14 adds a separate challenge set designed to expose retrieval weaknesses.

The challenge set contains 12 cases.

## Challenge types

- Lexical mismatch: question wording differs from wording in the evidence.
- Multi-evidence: a question requires more than one expected chunk.
- Ranking: relevant evidence competes against plausible but less relevant chunks.

## Distractors

Each case records explicit distractor chunk IDs from the controlled corpus. This makes expected evidence and plausible alternatives inspectable in advance.

## Evaluation policy

Precision@K, Recall@K, MRR, and nDCG remain unchanged. The challenge set is evaluated separately from the 40-question core benchmark so historical benchmark results remain comparable.

## Limitation

The challenge set is small and derived from a compact two-source corpus. It is an engineering stress test, not a statistically representative clinical retrieval benchmark.

## Freeze

V4.14 is complete when the 12 cases pass schema validation, evidence resolution, and CI.
