# V4.15 Failure Classifier Upgrade

V4.15 upgrades deterministic failure detection to consume the stronger signals introduced during V4 hardening.

## New signals

- Semantic unsupported-claim rate can drive hallucination detection when available.
- Semantic correctness below 0.5 produces an incorrect-interpretation failure.
- Semantic completeness below 0.5 produces an incomplete-answer failure.
- Partial retrieval of a multi-evidence benchmark case produces a ranking-failure signal.

## Conservative precedence

Semantic signals supplement rather than replace the existing deterministic metrics. If semantic grounding is unavailable, the lexical grounding signal remains the fallback.

The severity engine is unchanged. Existing failure taxonomy categories and types remain frozen.

## Regression

The existing severity regression suite remains mandatory. New classifier tests cover semantic and partial-retrieval signals.

## Limitation

The semantic evaluator is model-assisted and is not clinical ground truth. Classifier output remains a triage signal, not a clinical risk score.

## Freeze

V4.15 completes the V4 hardening phase. Further classifier changes require an explicit new design decision.
