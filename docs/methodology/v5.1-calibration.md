# V5.1 — Semantic Evaluator Calibration

## Goal

Measure how closely the model-assisted semantic evaluator agrees with human
reviewers on a controlled calibration sample.

This does not claim that human labels are clinical ground truth. It tests
whether the evaluator is aligned with a defined review rubric.

## Scope

V5.1 adds:

- a versioned human-label schema
- explicit annotation rules
- calibration agreement metrics
- validation and unit tests
- an empty versioned calibration dataset

It does not change the production QA path or replace existing lexical metrics.

## Review dimensions

- correctness
- completeness
- relevance
- faithfulness
- unsupported_claim_rate

Each score is on a continuous 0–1 scale.

## Agreement metrics

For each dimension:

- Mean absolute error: average absolute difference between model and human scores.
- Mean bias: average model score minus human score. Positive means over-scoring.
- Within-tolerance rate: proportion of labels whose absolute difference is at or below 0.20.

No composite evaluator score is introduced.

## Calibration procedure

1. Select a fixed subset of ClinicalQA-v1 items.
2. Run the same evaluator configuration used by the system.
3. Freeze the model outputs used for calibration.
4. Have a qualified reviewer score the five dimensions using the rubric.
5. Store human labels without modifying model scores.
6. Run the calibration analysis.
7. Inspect disagreements rather than optimizing directly against this sample.
8. Record reviewer methodology separately from benchmark data where appropriate.

## Current state

The repository does not contain human-reviewed labels yet. Therefore V5.1
does not make an empirical claim about evaluator agreement.

A future calibration run may populate
data/calibration/clinicalqa_v1_calibration.json.

## Freeze criterion

V5.1 is complete when:

- the annotation contract is versioned
- calibration data validates
- agreement metrics are deterministic
- tests pass in CI
- production evaluator behavior is unchanged
- limitations are explicit

Human annotation is a manual research step and is not fabricated by the implementation.
