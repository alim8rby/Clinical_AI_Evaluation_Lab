# Controlled clinical corpus

V2.1 uses a small depression-only evidence corpus derived from authoritative public guidance.

Sources:
- World Health Organization — Depression fact sheet.
- National Institute for Health and Care Excellence — Depression in adults: treatment and management (NG222).

The stored content is a compact evidence snapshot, not a verbatim copy of the source documents. Each record preserves source organization, publication date, and canonical URL.

The V1 ingestion and preprocessing pipeline is the canonical path for producing chunks. The benchmark must reference the resulting stable chunk IDs.

This corpus is an engineering seed. It is not a clinically validated knowledge base.
